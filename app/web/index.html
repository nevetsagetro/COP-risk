01 · CONTEXT

What is the model estimating?

The Home Credit baseline estimates the probability of the source-provided TARGET for an application enriched with static historical aggregates. It is a classification experiment, not a new lending decision or a temporal forecast.

InterpretationA probability ranks academic cases by estimated association with the target; it is not a certainty.
InputsApplication + aggregated history→OutputAcademic probability for TARGET
02 · DATA BOUNDARY

Which evidence is open to the model?

We fit on train, select with train cross-validation, evaluate the selected candidates on validation, and keep the final test unopened. The split is entity-disjoint and static because the source archive has no defensible application timestamp.

What this protectsSelection decisions do not use the final test.

07 · POLICY

What changes when review capacity changes?

Instead of pretending one threshold is universal, we rank validation cases and vary the fraction available for review. More capacity usually finds more target-positive cases while reducing precision.

Policy readingCapacity is an operating assumption, not a model metric.

What if review capacity is limited?

The Home Credit policy report ranks validation cases by estimated probability and measures what is found when only a fixed fraction can be reviewed.
