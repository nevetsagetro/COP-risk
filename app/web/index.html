WHAT THE MODEL PREDICTS

Will a default be recorded next month?

The academic dataset contains credit histories. For each case, the model returns an estimated probability of a default next month. It does not predict income, approval, or credit rejection.

InputPayment history, balances and payments made→OutputAcademic probability of a next-month default

THE FULL STORY

From dataset to final model decision

Academic evidence chain

COP keeps the reasoning visible: first we define what the data can support, then we train and compare models, and only then do we choose an academic operating point. Each step has a different role.

01 · DATASET

Start with a public source

UCI Default of Credit Card Clients, 30,000 rows and 19 approved input variables.

Target: default_payment_next_month
02 · CONTRACT

Define what is allowed

Missing values fail validation. Protected/audit-only attributes stay physically outside the model inputs.

Use: academic baseline only
03 · SPLITS

Protect the evidence

Train is used to fit and tune, validation compares decisions, and test remains unopened until explicit finalization.

21,000 train · 4,500 validation · 4,500 test
04 · EXPERIMENT

Try controlled candidates

Logistic Regression, LightGBM and KNN are evaluated with reproducible cross-validation and recorded parameters.

Selection metric: Average Precision
05 · OPERATING POINT

Translate scores into alerts

The threshold is learned from train out-of-fold predictions; F1 explains the balance between coverage and alert accuracy.

Default reference: 0.50 · tuned threshold shown in Model Development
06 · DECISION

Make a bounded academic conclusion

Run Model Development to identify the strongest candidate under the selected metric. This does not authorize production use.

Final test: closed by default

How was the model improved?

This experiment compares Logistic Regression and LightGBM. It tests parameters on training cross-validation, learns an alert threshold from out-of-fold predictions, and evaluates the selected candidates on validation. The final test remains closed.

INTERACTIVE LAB

What do we gain by moving the alert?

Lowering the threshold seeks more coverage. Raising it demands more evidence and usually improves precision. F1 helps show the balance.

A threshold of 0.50 means: estimated probability ≥ 50% → academic alert. It is not a certainty.
